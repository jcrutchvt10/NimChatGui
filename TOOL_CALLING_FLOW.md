                        MESSAGE FLOW EXAMPLE
???????????????????????????????????????????????????????????????????????

Conversation History Evolution:

1. Initial:
   [
     { role: "user", content: "What's the weather in NYC?" }
   ]

2. After first API call (AI requests tool):
   [
     { role: "user", content: "What's the weather in NYC?" },
     { 
       role: "assistant", 
       content: "",
       tool_calls: [
         {
           id: "call_123",
           type: "function",
           function: {
             name: "get_weather",
             arguments: '{"location": "New York, NY"}'
           }
         }
       ]
     }
   ]

3. After executing tool:
   [
     { role: "user", content: "What's the weather in NYC?" },
     { role: "assistant", content: "", tool_calls: [...] },
     { 
       role: "tool",
       content: '{"temp": 72, "condition": "sunny"}',
       tool_call_id: "call_123"
     }
   ]

4. After final API call:
   [
     { role: "user", content: "What's the weather in NYC?" },
     { role: "assistant", content: "", tool_calls: [...] },
     { role: "tool", content: '{"temp": 72...}', tool_call_id: "call_123" },
     { 
       role: "assistant",
       content: "The weather in NYC is sunny with a temperature of 72°F"
     }
   ]

                    MULTI-TURN CONVERSATION EXAMPLE
???????????????????????????????????????????????????????????????????????

User:    "What's the weather in NYC and LA, then tell me which is warmer?"

AI:      ? Requests 2 tool calls
         1. get_weather(location="New York, NY")
         2. get_weather(location="Los Angeles, CA")

System:  ? Executes both tools
         1. Returns: {"temp": 72, "condition": "sunny"}
         2. Returns: {"temp": 78, "condition": "partly cloudy"}

AI:      ? Uses results to generate response
         "Currently it's 72°F and sunny in NYC, while LA is 78°F and 
          partly cloudy. Los Angeles is warmer by 6 degrees."
