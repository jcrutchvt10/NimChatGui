# MCP Catalog - Quick Start Guide

## ?? Get Started in 30 Seconds

### Step 1: Open the Catalog (5 seconds)
1. Launch NIM Chat GUI
2. Look at the left sidebar
3. Click **"Browse MCP Servers"** (blue button at bottom)

### Step 2: Browse Servers (10 seconds)
- Catalog automatically loads
- See 8+ sample servers by default
- Each card shows: Name, Description, Command, Category

### Step 3: Install a Server (10 seconds)
1. Find a server you like (e.g., "filesystem")
2. Click **"Add"** button
3. Confirm in the dialog
4. Done! Server is now installed

### Step 4: View Installed (5 seconds)
- See installed count at bottom
- Click **"View Installed"** to see your servers
- Click **"Remove"** to uninstall

## ?? Popular Use Cases

### Case 1: Add File Access
**Want AI to read/write files?**
1. Search for "filesystem"
2. Click "Add"
3. Configure path in command
4. AI can now access your files

### Case 2: Add GitHub Integration
**Want AI to work with GitHub?**
1. Search for "github"
2. Click "Add"
3. Set GITHUB_TOKEN env var
4. AI can create issues, read repos

### Case 3: Add Web Search
**Want AI to search the web?**
1. Search for "brave-search"
2. Click "Add"
3. Get Brave API key
4. AI can search current info

## ?? Tips & Tricks

### Quick Search
- Type in search box: "file", "git", "web", etc.
- Results filter instantly
- Try searching by category name

### Filter by Category
- Click the category dropdown
- Choose: Files, Development, Database, Web, etc.
- See only servers in that category

### Refresh Catalog
- Click "Refresh Catalog"
- Gets latest from GitHub
- Updates with new servers

### Read Details
- Each card shows full command
- Click "Source" to see GitHub repo
- Read description for capabilities

## ?? Common Issues

### "Using sample catalog"
- **Reason**: Can't reach GitHub
- **Solution**: Check internet or use sample catalog
- **Impact**: None, sample catalog works fine

### Button says "Remove"
- **Reason**: Server already installed
- **Solution**: Click to uninstall, then reinstall
- **Impact**: None

### Can't see my server
- **Check**: Search box is empty
- **Check**: Category filter is "All Categories"
- **Solution**: Clear filters
